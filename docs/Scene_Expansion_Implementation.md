# 장면 확장 구현·검증 기록

기준: 사용자 제공 장면 확장 설계서 v1.0 및 바이브코딩 프롬프트 v1.0. 기준 소스 `817beb9`. 작성일 2026-11-21. 후보 버전 `3.1.0-rc.1`.

카드 문구와 음향 정책은 AI 초안·교사 검토 전 상태를 유지한다. 자동화는 실제 iPhone Safari의 소리·저장·파일 공유, 교실 전자칠판의 가독성·터치·리모컨·성능, NVDA·VoiceOver 검수를 대체하지 않는다.

## 재현 명령

```sh
cd music-chalkboard-r1
npm ci
npm test
npm run build
npm run build:rhythm-prototype
git diff --exit-code -- dist/index.html prototypes/rhythm/index.html
npx playwright install --with-deps chromium webkit
npm run test:e2e
```

로컬 단위·통합 시험과 두 단일 HTML 빌드를 확인한다. 이 작업 환경은 브라우저 다운로드와 Chromium 소켓 생성을 제한하므로 실제 두 브라우저 실행은 저장소 CI 결과를 기록한다. 브라우저 시험의 소리는 음 생성 요청과 예약 시각으로 검사하며 실청 결과로 기록하지 않는다.

## 저장·복구

DB_VERSION·파일 version·초안 editorVersion은 2, 장면 schemaVersion도 2다. 오선 새 기능이 실제 필요할 때만 templateVersion 3이고 도식은 templateVersion 1이다. 기존 자료는 읽기만으로 덮어쓰지 않는다. 새 수업 생성은 ID 충돌·용량·요청 실패 시 장면·수업·순서 모두 되돌린다.

오선3·도식이 포함된 자료는 이전 빌드가 읽을 수 없다. 복구는 확장 형식을 읽는 빌드를 사용하고 먼저 현재 장면·초안·수업 파일을 보관한다. 기존 원본은 삭제하지 않는다. 카드 재생성은 변경 확인 뒤 별도 초안을 만들며 취소한 경우 편집 내용을 유지한다.
